### 아마존 계정을 연동하는 중에 오류가 발생했어요.

Amazon 광고 계정을 연동하는 중에 문제가 발생하셨나요? 아래의 안내를 따라 문제를 해결해 보세요:

1. **권한 확인 :** 연동하려는 계정에 **‘관리자(Admin)’ 권한** 또는 **‘모든 캠페인 보기(View & Edit All Campaigns)’ 권한**이 있는지 확인해야 합니다.
    - 확인 방법:
        1. **Amazon 광고 콘솔에 로그인**
        2. Account access & Setting 메뉴 → '계정 설정(Accounts)'으로 이동
        3. **'사용자(User Permissions)' 섹션**에서 본인의 권한을 확인
        - 연동하려는 계정에 ‘관리자’ 권한 또는 최소한 ‘모든 캠페인 보기(View)’ 권한이 있어야 연동이 가능합니다.
        - 만약 권한이 부족하다면 계정 관리자에게 요청하여 권한을 부여받아야 합니다.
2.  **광고 계정 연동 상태 확인 :** Amazon 광고 계정을 여러 개 사용하는 경우, 원하는 광고 계정이 연동 대상에 포함되어 있는지 확인해야 합니다.
    - 확인 방법:
        1. **광고 콘솔에 로그인**
        2. **좌측 상단의 계정 선택 메뉴에서 연동하려는 계정 선택**
        3. 해당 계정의 ‘계정 설정(Account Settings)’ → '연결된 계정(Linked Accounts)'을 확인
            - 연동하려는 계정이 ‘활성(Active)’ 상태로 표시되어야 합니다.
3. **토큰 확인:** 연동하려는 Amazon 광고 계정의 인증 토큰이 올바른지 확인하세요. 토큰이 이미 다른 계정에 연결되어 있거나 만료되었을 수 있습니다. 
이 경우, [고객 지원팀](https://pulsead.io/inquiry)에 문의하여 토큰을 재설정하거나 새로운 토큰을 발급받으세요.
4. **연동 절차 재시도:** 연동 과정에서 브라우저 창을 닫았거나 절차를 완료하지 못한 경우, 연동이 중단될 수 있습니다. 이러한 경우, 다시 한 번 연동 절차를 처음부터 따라 진행해 보세요.
5. **고객 지원 문의:** 위의 방법으로도 문제가 해결되지 않으면, [고객 지원팀](https://pulsead.io/inquiry)에 문의하세요.

### 계정을 연동했는데도 대시보드를 확인 할 수 없어요.

아마존 계정 연동이 성공적으로 완료된 후 데이터가 수집되고 분석되기까지 최대 **48시간**이 소요될 수 있어요. 연동 직후에는 대시보드에 데이터가 표시되지 않더라도 걱정하지 마시고 잠시만 기다려 주세요!
연동 후에도 대시보드를 확인할 수 없다면 다음 내용을 확인해 보세요:

1. **계정 연동 상태 확인**
    - 설정 메뉴 에서 계정 연동이 제대로 완료되었는지 다시 한 번 확인해 주세요.
    - 연동 시 입력한 계정 정보가 올바른지, 연동 중 오류 메시지가 발생하지 않았는지 체크해 보시는 것이 좋아요.
2. **권한 문제 확인**
    - 연동한 아마존 광고 계정에 필요한 권한(관리자 권한 또는 모든 캠페인 보기 권한)이 있는지 확인하세요.
    - 권한이 부족한 경우, 대시보드에 데이터가 정상적으로 표시되지 않을 수 있어요. 계정 관리자에게 권한을 요청하거나 권한을 부여받은 후 다시 연동을 시도해 주세요.
3. **시간 지연 가능성**
    - 일부 경우, Amazon Advertising에서 데이터를 수집하고 처리하는 과정이 지연될 수 있어요. 이 과정에서 약간의 시간이 더 필요할 수 있으니 **최대 48시간**을 기다려 주세요.
4. **여전히 문제가 지속된다면**
    - 위의 내용을 확인했음에도 여전히 문제가 해결되지 않는다면, [고객 지원팀](https://pulsead.io/inquiry)에 문의해 주세요. 연동 상태와 데이터를 빠르게 확인하여 도와드리겠습니다.
    - 문의 시 연동한 계정 정보(광고 계정 ID)와 **연동 시점**을 함께 제공해 주시면 보다 신속하게 도와드릴 수 있어요!

### 리포트 데이터의 업데이트 주기와 조회기간을 알고 싶어요.

펄스애드 리포트 데이터는 정기적으로 업데이트되어 항상 최신 정보를 제공하고 있어요. 리포트의 종류에 따라 업데이트 주기와 조회 가능한 데이터 기간이 다르니 아래 내용을 참고해 주세요!

1. **데일리 리포트**
    - **업데이트 주기:** 매일 오전 **8시~9시(GMT +9)** 사이에 전일 데이터를 기준으로 리포트가 업데이트됩니다.
    - **조회 기간:** 최신 데이터는 전일까지의 집계 결과로 제공됩니다.
2. **시간별 리포트**
    - **업데이트 주기:** 매시간 업데이트되며, **최대 2시간 전**의 데이터까지 반영됩니다.
    - **조회 기간:** 시간별 리포트는 당일 실시간으로 데이터를 확인할 수 있으며, 매시간 갱신된 정보를 제공합니다.
3. **타임존 안내**
    - 아마존 광고 데이터는 기본적으로 광고를 집행하는 **각 마켓에 맞는 현지 시간**(local time)으로 제공됩니다.
    즉, 광고를 집행하는 마켓의 타임존에 맞춰 데이터를 제공하고 있습니다.
        - 미국 마켓: PST(태평양 표준시, UTC-8) 기준
        - 일본 마켓: JST(일본 표준시, UTC+9) 기준
        - 유럽 마켓: 각 지역별 현지 시간 기준 (예: CET, GMT 등)
        - 한국 마켓(KR): KST(한국 표준시, UTC+9) 기준으로 제공될 수 있어요.

### 광고 콘솔 데이터와 펄스애드의 대시보드 수치 차이는 왜 발생하나요?

광고 콘솔과 펄스애드 대시보드 간의 수치가 다르게 보일 수 있는 이유는 여러 가지 요인에 따라 발생할 수 있어요. 아래 주요 원인을 참고해 주세요:

**1. 데이터 동기화 시점 차이**

- 광고 콘솔의 데이터는 **실시간** 업데이트되는 반면, 펄스애드 대시보드는 **정해진 주기**에 따라 데이터를 수집하고 반영하기 때문에 **최대 2~3시간 정도의 시간차**가 발생할 수 있습니다.
- 특히 시간별 리포트를 확인할 때, 최근 데이터는 약간의 지연이 있을 수 있으니 참고해 주세요.

---

**2. 필터링 및 집계 방식 차이**

- 광고 콘솔과 펄스애드 대시보드에서 **캠페인, 광고 그룹, 키워드 수준의 필터링 조건** 또는 **데이터 집계 방식**이 다를 수 있습니다.
- 예를 들어, 펄스애드에서는 사용자가 특정 조건에 맞게 커스텀 필터를 적용할 수 있는데, 이로 인해 아마존 광고 콘솔의 기본 리포트와 차이가 발생할 수 있습니다.

---

**3. 데이터 처리 지연 또는 누락**

- 드물지만 광고 콘솔에서 데이터를 제공하는 Amazon API의 지연으로 인해 펄스애드 대시보드에 일부 데이터가 늦게 반영되거나 누락될 수 있습니다.
- 이 경우 일정 시간 이후 다시 확인하시면 정상적으로 반영된 데이터를 확인하실 수 있습니다.

---

**4. Amazon 광고 콘솔과 API 데이터 차이**

Amazon 광고 데이터는 **광고 콘솔 대시보드**와 **API**를 통해 제공되는데, Amazon 자체적으로 두 데이터 간에 미세한 차이가 발생할 수 있어요.

- **실시간 반영 여부:**광고 콘솔 대시보드는 일부 데이터를 실시간으로 반영하지만, API 또는 리포트에서 제공하는 데이터는 일정 주기(최대 몇 분~몇 시간)로 집계되어 제공되기 때문에 데이터 동기화 시점에 따라 미세한 차이가 발생할 수 있습니다.
- **후처리 데이터**:Amazon 광고 콘솔에서는 특정 필터링 또는 사후 데이터 정정을 통해 수정된 데이터를 제공하는 반면, API에서는 정정 이전의 데이터를 반환할 수 있습니다. 이로 인해 클릭 수, 노출 수, 비용 등의 수치에 미세한 차이가 생길 수 있어요. ****

---

**💡수치 차이를 해결하려면?**

1. 데이터 동기화 시점을 고려하여 **최대 2~4시간 후** 다시 확인해 주세요.
2. 광고 콘솔과 펄스애드의 **필터 설정**이 동일한지 확인해 주세요.
3. 광고 콘솔의 대시보드와 펄스애드 데이터가 차이가 난다면 아마존 리포트 데이터와 펄스애드 데이터를 비교해보세요.
4. **여전히 문제가 지속된다면**
    - 위의 내용을 확인했음에도 여전히 문제가 해결되지 않는다면, [고객 지원팀](https://pulsead.io/inquiry)에 문의해 주세요. 데이터를 빠르게 검증하여 확인을 도와드리겠습니다.
    - 문의 시 확인하신 아마존 대시보드 데이터나 스크린샷을 함께 제공해 주시면 보다 신속하게 도와드릴 수 있어요!

### 펄스애드 리포트의 데이터를 추출할 수 있나요?

펄스애드에서 제공하는 대시보드에 있는 **다운로드 버튼**을 통해 리포트를 **PDF** 또는 **Excel 파일 형식**으로 손쉽게 다운로드 받으실 수 있습니다. 

필요한 데이터를 원하는 형식으로 저장하고 활용해 보세요!

만약 **대시보드에 표시되지 않는 추가적인 데이터**나 **커스텀 리포트**가 필요하시다면, 펄스애드의 구독 서비스를 통해 데이터를 추출할 수 있도록 도와드리고 있습니다.

구독 서비스를 신청하시려면 **아래 상담 버튼**을 통해 상담 신청해 주세요. 

담당자를 통해 빠르게 안내드리겠습니다!

### 원하는 대시보드를 생성할 수 있나요?

네, 가능합니다! 펄스애드는 **비즈니스 플랜**으로 가입한 고객사에 한해 커스텀 대시보드 서비스(베타 기능)를 제공하고 있어요. 고객사의 필요에 따라 맞춤형 대시보드를 설계하여 더욱 효과적인 리포팅이 가능하도록 지원합니다.

**커스텀 대시보드 제공 방식:**

1. **컨설턴트와의 상담을 통한 맞춤 설계**
    - 고객사의 요구 사항을 바탕으로 펄스애드 컨설턴트가 최적화된 대시보드를 설계해 드립니다.
2. **직접 생성할 수 있는 유료 서비스 제공**
    - 필요에 따라 고객사가 직접 원하는 대시보드를 생성할 수 있도록 지원하는 **유료 서비스**도 제공하고 있어요.
